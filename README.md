# MidWest Suppliers Meats & Seafood Website Prototype

Static GitHub Pages prototype for a Midwest meat/seafood distributor.

## Included
- Rustic deadwood visual direction and generated meat/seafood photography.
- Mouse/scroll-reactive Three.js 3D mock models: steak, ham, shrimp.
- Menu brochure page ready for the official brochure/logo assets.
- Online order form mock that saves draft order data locally.
- Live inventory AI chatbot mock with sample stock responses.

## Source notes
Public search result/Facebook listing surfaced: “We are the Midwest #1 Source for delicious top quality meats and seafood. We offer 100 % free delivery.” Facebook itself required login for detailed scraping, and the existing website returned 503/SSL errors during this build.
